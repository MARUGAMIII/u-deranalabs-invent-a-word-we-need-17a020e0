One invented English word for make.fun's "Invent a Word We Need" bounty ($5 in USDC). The word is **cancelief** — the guilty relief when a dreaded plan is cancelled. English has FOMO and JOMO, but no word for that exact guilty sigh of relief when the group chat says "let's rain-check".

## Run it

```sh
python3 main.py
```

This writes the entry to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`).
